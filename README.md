# User Account Database Example

A small PHP example of a user account system with registration, login, logout, and a members page.

## Files

- `newUser.php` — user registration
- `login.php` / `logout.php` — sign-in and sign-out
- `members.php` — members page
- `db_connect.php` — database connection
- `styles.css` — page styles

## Setup

Configure your database connection in `db_connect.php`, then run the project on a PHP server with the required database set up.

This project is for learning and demonstration purposes.
